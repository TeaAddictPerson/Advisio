# Решение проблем с API Kufar и Kvitki

## Текущая ситуация:

### Kufar API:
- **Проблема**: Возвращает пустые ответы `{"ads":[],"total":0}` для всех категорий
- **Причина**: Возможно, API изменился, требует другие параметры или аутентификацию

### Kvitki API:
- **Проблема**: Endpoint `/api/refresh` возвращает `{"responseData":[],"responseStatus":"fail"}`
- **Причина**: Требуется аутентификация (cookies сессии или другие параметры)

## Что уже сделано:

1. ✅ Расширен список категорий Kufar (1700, 1701, 1702, 1703, 1600, 1500, 1000, 2000)
2. ✅ Добавлен параметр `lang=ru` для запросов Kufar
3. ✅ Добавлена поддержка cookies для Kvitki API
4. ✅ Улучшено логирование ответов API

## Как проверить, работает ли API:

1. Откройте сайт в браузере (Kufar.by или Kvitki.by)
2. Откройте DevTools (F12) → Network
3. Выполните поиск на сайте
4. Найдите запросы к API
5. Скопируйте:
   - Полный URL запроса
   - Все заголовки (Headers)
   - Структуру ответа (Response)
6. Используйте эту информацию для обновления кода
