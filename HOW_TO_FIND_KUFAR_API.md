# Как найти правильные запросы к API Kufar

## ❌ Это НЕ тот запрос!

Запрос к `api.rudderstack.com` - это аналитический сервис (трекинг событий), а не API для получения объявлений.

## ✅ Что нужно искать:

### 1. Откройте сайт Kufar.by

1. Перейдите на https://www.kufar.by
2. Откройте DevTools (F12)
3. Перейдите на вкладку **Network** (Сеть)

### 2. Выполните поиск объявлений

1. На сайте Kufar выполните поиск, например:
   - Введите в поиск "развлечения" или "досуг"
   - Или выберите категорию "Развлечения и досуг"
   - Или просто откройте любую категорию объявлений

2. В DevTools → Network ищите запросы, которые:
   - Содержат `api.kufar.by` в URL
   - Имеют тип `xhr` или `fetch`
   - Возвращают JSON с данными объявлений

### 3. Правильные запросы должны выглядеть так:

```
https://api.kufar.by/search-api/v1/search/rendered-paginated?cat=1700&rgn=1&size=100&sort=lst.d&cur=0
```

Или похожие варианты:
- `api.kufar.by/search-api/...`
- `api.kufar.by/v1/...`
- `api.kufar.by/ads/...`

### 4. Что НЕ искать:

❌ `api.rudderstack.com` - аналитика
❌ `google-analytics.com` - аналитика
❌ `googletagmanager.com` - теги
❌ `facebook.com` - социальные сети
❌ `yandex.ru` - аналитика
❌ Статические ресурсы (CSS, JS, изображения)

### 5. Как распознать правильный запрос:

✅ URL содержит `api.kufar.by`
✅ Метод: GET
✅ Response содержит JSON с полями типа:
   - `ads` или `items` или `results`
   - `total`
   - `pagination`
✅ В Response есть данные об объявлениях (названия, цены, адреса)

### 6. Пример правильного запроса:

**URL:**
```
https://api.kufar.by/search-api/v1/search/rendered-paginated?cat=1700&rgn=1&size=100&sort=lst.d&cur=0
```

**Параметры:**
- `cat=1700` - категория (1700 = Развлечения)
- `rgn=1` - регион (1 = Минск)
- `size=100` - размер страницы
- `sort=lst.d` - сортировка
- `cur=0` - текущая позиция

**Response должен содержать:**
```json
{
  "ads": [
    {
      "subject": "Название объявления",
      "body": "Описание",
      "location": {...},
      "images": [...]
    }
  ],
  "total": 1234,
  "pagination": {...}
}
```

### 7. Пошаговая инструкция:

1. Откройте https://www.kufar.by
2. F12 → Network
3. Очистите список запросов (кнопка 🚫)
4. На сайте выберите категорию "Развлечения и досуг"
5. В Network найдите запросы к `api.kufar.by`
6. Кликните на запрос
7. Посмотрите:
   - **Headers** → Request URL (полный URL с параметрами)
   - **Payload** → Query String Parameters (параметры запроса)
   - **Response** → JSON с данными

### 8. Если не видите запросы:

- Убедитесь, что фильтр в Network не скрывает запросы
- Попробуйте другой поиск/категорию
- Обновите страницу
- Проверьте, что включен фильтр "XHR" или "Fetch"

### 9. Альтернативный способ:

Если на сайте не видно запросов к API, возможно:
- API используется только в мобильном приложении
- API требует аутентификацию
- API изменился и больше не используется на сайте

В этом случае:
- Изучите мобильное приложение Kufar
- Используйте инструменты для перехвата трафика (Charles Proxy)
- Обратитесь в поддержку Kufar для получения доступа к API
