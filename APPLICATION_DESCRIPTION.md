# Advisio - Подробное описание приложения для дизайна

## Общая информация

**Advisio** - веб-приложение для рекомендаций мест отдыха с персонализацией на основе предпочтений пользователя. Приложение использует систему опросов, лайков и избранного для формирования персональных рекомендаций.

**Технологии**: ASP.NET Core Razor Pages, Bootstrap 5, JavaScript, SQL Server

---

## Структура навигации

### Шапка сайта (Header)
- **Логотип/Название**: "Advisio" (слева, ссылка на главную)
- **Основное меню** (горизонтальное):
  - Главная
  - Места
  - Рекомендации
  - Опрос
- **Правая часть** (зависит от авторизации):
  - **Неавторизованный пользователь**: 
    - Кнопка "Войти"
    - Кнопка "Зарегистрироваться"
  - **Авторизованный пользователь**:
    - Иконка пользователя + имя пользователя (ссылка на профиль)
    - Кнопка "Выйти"
  - **Администратор**:
    - Те же элементы + доступ к админ-панели (через прямой URL)

## Цветовая схема и стили

### Цвета Bootstrap:
- **Primary** (синий): Основные кнопки, ссылки, бейджи категорий
- **Success** (зеленый): Бейджи типов мест, карточки рекомендаций
- **Warning** (желтый): Кнопки избранного, кнопки редактирования
- **Danger** (красный): Кнопки лайков, кнопки удаления
- **Info** (голубой): Информационные блоки, бейджи количества лайков
- **Secondary** (серый): Бейджи категорий, второстепенные элементы

### Специальные стили:
- **place-description**: 
  - white-space: pre-line (сохраняет переносы строк)
  - Поддержка жирного текста через `<strong>`

### Иконки:
- Используется Bootstrap Icons (bi-*)
- Основные иконки:
  - bi-person-circle: Профиль пользователя

  - bi-star / bi-star-fill: Избранное
  - bi-geo-alt / bi-geo-alt-fill: Геолокация
  - bi-map: Карта
  - bi-pencil: Редактирование
  - bi-trash: Удаление
  - bi-plus-circle: Добавление
  - bi-arrow-clockwise: Синхронизация
  - bi-tags: Категории

  - bi-info-circle: Информация
